# 💻 Projetos Pessoais

📌 Descrição
Coleção de exercícios e projetos desenvolvidos pessoalmente para praticar e consolidar conhecimentos em Java, cobrindo desde exercícios simples até projetos mais complexos.

🚀 Tecnologias
- Java
- Orientação a Objetos
- Swing
- Estruturas de Dados

🎯 Funcionalidades
- Classes de modelo (Aluno, Funcionário, Produto, etc)
- Sistemas de controle e gerenciamento
- Interface gráfica com Swing
- Aplicações de lógica de negócio

▶️ Como rodar
```bash
# Projetos simples
cd d:\git-hub\java\pessoal\exercicios\[projeto]\src
javac *.java
java Main

# Projetos com estrutura organizada
cd d:\git-hub\java\pessoal\[projeto]
javac -d bin src/**/*.java
java -cp bin br.Main
```

📚 Aprendizados
- Prática com exercícios diversos
- Aplicação de conceitos OOP
- Desenvolvimento de sistemas simples
- Consolidação de conhecimentos
