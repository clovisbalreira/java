# 🎬 Alura Filmes

📌 Descrição
Projeto desenvolvido durante os cursos da Alura focado em manipulação de dados de filmes, aplicação de conceitos de programação orientada a objetos e estruturas de dados em Java.

🚀 Tecnologias
- Java
- Estruturas de Dados
- Orientação a Objetos

🎯 Funcionalidades
- Leitura de dados de filmes (CSV)
- Manipulação e armazenamento de informações
- Aplicação de conceitos OOP
- Processamento de dados

▶️ Como rodar
```bash
cd d:\git-hub\java\alura\alura-filmes
javac -d bin src/br/com/*.java
java -cp bin br.com.Main
```

📚 Aprendizados
- Trabalhando com arquivos e leitura de dados
- Implementação de classes e objetos
- Estruturas de dados e manipulação
- Princípios de orientação a objetos
