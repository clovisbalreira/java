# 🎓 Curso em Vídeo - Java Básico

📌 Descrição
Série de exercícios e projetos práticos do curso de Java Básico do Gustavo Guanabara, cobrindo fundamentos da linguagem, estruturas de controle, operadores e introdução a conceitos importantes.

🚀 Tecnologias
- Java
- Lógica de Programação
- Estruturas de Controle
- GUI (Swing/JavaFX)
- Maven

🎯 Funcionalidades
- Calculadora de idade
- Cálculo de factorial
- Sistema de contadores
- Equações do segundo grau
- Interface gráfica com Swing
- Leitura do sistema

▶️ Como rodar
```bash
# Projetos simples
cd d:\git-hub\java\curso-em-video\curso-em-video-java-basico\src
javac calculadorIdade/Idade.java
java calculadorIdade.Idade

# Projetos com JavaFX
cd d:\git-hub\java\curso-em-video\curso-em-video-java-basico
mvn javafx:run
```

📚 Aprendizados
- Fundamentos de Java
- Variáveis, tipos de dados e operadores
- Estruturas de controle (if, switch, loop)
- Funções e métodos
- Introdução a GUI com Swing
- Manipulação de dados do sistema
