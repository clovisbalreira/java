# 🏗️ Curso em Vídeo - Java POO

📌 Descrição
Série completa de exercícios progressivos sobre Programação Orientada a Objetos (POO) em Java do Gustavo Guanabara. Cobre desde os conceitos básicos de classes até polimorfismo e relacionamento entre objetos.

🚀 Tecnologias
- Java
- Programação Orientada a Objetos
- Herança
- Polimorfismo
- Encapsulamento

🎯 Funcionalidades
- Classes básicas e objetos
- Modificadores de acesso (public, private, protected)
- Getters e Setters
- Construtores
- Herança simples e múltipla
- Polimorfismo por sobrescrita
- Polimorfismo por sobrecarga
- Relacionamento de classes (associação e agregação)
- Projeto final integrador

▶️ Como rodar
```bash
cd d:\git-hub\java\curso-em-video\curso-em-video-java-poo\src
javac aula01_OlaMundo/OlaMundo.java
java aula01_OlaMundo.OlaMundo

# Para outras aulas
javac aulaN_*/Classe.java
java aulaN_.Classe
```

📚 Aprendizados
- Conceitos fundamentais de OOP
- Encapsulamento de dados
- Herança e reutilização de código
- Polimorfismo e sobrecarga de métodos
- Boas práticas de design orientado a objetos
- Relacionamento entre classes
- Desenvolvimento de projetos integrados
