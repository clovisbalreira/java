## ▶️ Como rodar

### Projetos simples (sem build tool)
```bash
cd caminho/do/projeto
javac Arquivo.java
java Arquivo
```

### Projetos com Maven
```bash
cd caminho/do/projeto
mvn clean compile
mvn exec:java
```

### Projetos com Gradle
```bash
cd caminho/do/projeto
./gradlew build
./gradlew run
```

### Projetos JavaFX
```bash
cd caminho/do/projeto
mvn javafx:run
```

## 📝 Observações

- Cada pasta representa uma série de exercícios ou um projeto específico
- Os projetos seguem estruturas variadas de acordo com sua fonte e propósito
- Recomenda-se usar uma IDE como IntelliJ IDEA ou Eclipse para melhor experiência
