# 🗄️ DIO - Java com Banco de Dados

📌 Descrição
Projeto desenvolvido no curso DIO focado em integração de aplicações Java com bancos de dados, utilizando Gradle como ferramenta de build.

🚀 Tecnologias
- Java
- Gradle
- Banco de Dados
- JDBC
- Integração com dados

🎯 Funcionalidades
- Conexão com banco de dados
- Operações CRUD (Create, Read, Update, Delete)
- Gerenciamento de dependências com Gradle
- Automação de build

▶️ Como rodar
```bash
cd d:\git-hub\java\dio\curso_dio_java_banco_de_dados

# No Windows
gradlew build
gradlew run

# No Linux/Mac
./gradlew build
./gradlew run
```

📚 Aprendizados
- Integração com bancos de dados em Java
- Uso do JDBC
- Gerenciamento de dependências com Gradle
- Boas práticas em acesso a dados
- Arquitetura de aplicações com persistência
